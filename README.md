# kathisrestaurant.com

Website for **Kathis — American-Indian Wraps** (Yuba Sutter Marketplace, Yuba City, CA).

- Plain HTML, no build step. Everything is in `index.html` (styles inline).
- Photos in `images/`, tab/home-screen icons in `icons/` and `favicon.ico`.
- Hosted on GitHub Pages from the `main` branch (root). `CNAME` sets the custom domain.
- Changes go through pull requests; merging to `main` publishes within a minute or two.

## Common edits
- **Menu items / prices:** search `index.html` for the item name and change the text.
- **Hours:** search for `Opening soon. Hours will be posted here.`
- **Photos:** add the file to `images/` and point the `<img src>` at it. Keep photos around 800px wide.
